# 0010 — Kit « shadcn » : pricing, code, buttons, layouts landing et docs

**Contexte.** Il faut couvrir l'essentiel des pages (vente, documentation) avec
peu de pièces, d'un rendu propre, dans l'esprit de shadcn/ui.

**Options.**

1. Ajouter de nouveaux tokens (ombres, rayons, couleurs).
2. Composer avec les tokens existants : trois directives et deux layouts.

**Choix.** Option 2, sans nouveau token donc sans changement de direction visuelle.
Directives `pricing`, `code` (bouton Copier), `buttons`. Layouts `landing` et
`docs`. Frontmatter `nav:` pour un menu d'en-tête, `lead:` pour l'accroche.
